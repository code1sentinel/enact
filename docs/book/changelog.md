# Changelog

Release notes live in the repository [CHANGELOG.md](https://github.com/code1sentinel/enact/blob/main/CHANGELOG.md). Dates are UTC.

User-facing changes (app copy, CLI flags, writers, privacy) are recorded there under **Unreleased** until the next tagged version. This book does not duplicate the full log.

When you change a user-visible command or the in-browser walk-through, update `CHANGELOG.md` in the same PR as the code. If the Pages app or report HTML changed, rebuild the demo (`scripts/build_site.py`).
